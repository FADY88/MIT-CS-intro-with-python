# MIT CS Intro - OSSU Course 2 Progress

This repository documents my learning progress in the second course of the OSSU (Open Source Society University) roadmap: [MIT's Introduction to Computer Science and Programming with Python](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/pages/material-by-lecture/).

[YT playlist from MIT OpenCourseWare channel](https://youtube.com/playlist?list=PLUl4u3cNGP62A-ynp6v6-LGBCzeH3VAQB&si=4DbBHbfzbt-nBvGo)

It is a personal collection of exercises, notes, assignments, and Python scripts completed during the course. The goal of this repo is to track my understanding of core programming concepts and problem-solving techniques while building a solid foundation in computer science.

## Course focus

This course introduces fundamental concepts in programming and computer science, including:

- Python basics and syntax
- Variables, data types, and control flow
- Functions and modular design
- Lists, tuples, dictionaries, and strings
- Recursion and algorithmic thinking
- Searching and sorting algorithms
- Time complexity and Big O notation
- Exceptions, assertions, and debugging
- Object-oriented programming and classes
- Working with files and data processing
